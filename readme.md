# Travel Website

This is a travel website that showcases popular destinations and allows users to browse through services like hotels, flights, and booking options. The website includes features like theme switching, language switching, a testimonial slider, and destination displays.

## Features

- **Theme Toggle**: Users can toggle between light and dark themes. The selected theme is saved in `localStorage` so it persists across page reloads.
- **Language Switcher**: Supports language switching between English and Arabic.
- **Swiper Slider**: A vertical testimonial slider with autoplay, pagination dots, and custom navigation buttons.
- **Responsive Design**: The site is fully responsive and optimized for mobile devices.
- **Booking Process**: Three simple steps to book a trip (Choose destination, make payment, reach airport).

## Technologies Used

- **HTML5**: For structuring the webpage.
- **CSS3**: For styling and layout, including custom theme handling.
- **JavaScript**: For dynamic functionalities like theme switching, language change, and testimonial slider behavior.
- **Swiper**: A modern touch slider for the testimonials section.
- **Bootstrap**: For responsive design and UI components.
